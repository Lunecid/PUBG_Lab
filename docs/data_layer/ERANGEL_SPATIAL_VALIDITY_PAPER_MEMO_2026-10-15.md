## 2. 정확도는 아직 하나의 수치로 말할 수 없다

| 평가 대상 | 현재 증거 | 아직 모르는 것 / 필요한 정답 |
|---|---|---|
| 좌표 단위·방향·범위 | 공식 cm, 좌상단 원점, 816,000cm 범위와 래스터 대응 | 독립 랜드마크 기준 위치 RMSE; 현 대응의 절대 정합 오차 |
| 관측 범위 | 위 셀·전이 포괄률 | 미관측 경로가 통행 가능한지 여부 |
| 두 셀 사이 연결 | 조건을 통과한 동일 인물의 연속 위치 관측 | 샘플 사이 실제 경로, 직선 통과 가능성, 세부 진입/출구 |
| 높이 | 2019 높이와 학습 플레이어 고도의 차이를 요약 | 40.2 지면 높이 정답, 지면·건물 층·교량·점프의 분리 |
| 건물·교량 | 주변의 거시적 관측 전이 | collision mesh, 출입구, 벽, 층, 교량 상·하부 연결 |
| 지도 버전 | 시간으로 추정한 40.2 경기, 역사적 지도 파일 날짜 | 정확한 경기 build·핫픽스, 해당 빌드의 공간 원본 |
| 불확실성 | 지지 경기 수와 명시적 휴리스틱 flag | confidence 확률의 calibration, flag의 오류 탐지 precision/recall |
| 후속 생성기 | 아직 학습하지 않음 | 공간 표현이 예측/생성/행동 비교에 유용한지 |

**‘공간 정확도 99.88%’, ‘지도 복원 정확도 99.80%’, ‘97.98% 통행 가능’이라는 문장을 쓰지 않는다.** 해당 분모와 목적이 다르며 공간 정답과 대조하지 않았다. 이 수치들은 100m 해상도, 현재 코퍼스와 필터, 현재 분할에 조건부인 관측 포괄률이다.

관측 전이의 끝점을 연결한 선이 벽을 지나지 않는다는 보장은 없다. 격자 내 서로 다른 출입구를 무시하면 개별 관측 엣지를 이어 만든 긴 경로가 실현 불가능할 수도 있다. 자기 그래프를 생성의 조건과 유일한 평가자로 동시에 쓰면 순환 평가가 된다.

## 3. 원본·보정·경고의 출처

높이 파일은 커뮤니티 자료로 마지막 변경 2019-12-19, 공식 무문자 지도 파일은 마지막 변경 2024-10-28이다. 둘 다 40.2 공간 정답이 아니다. 정확한 원본 URL, 고정 커밋과 SHA-256은 [source manifest](/Users/lunecid/project/PUBG/data/spatial/erangel/source/manifest.json)에 보존했다.

현재 높이는 `(raw-32768)/128` 고정 근사 변환과 학습 987개 calibration 셀에서 계산한 0.90254m 오프셋을 사용했다. 플레이어 고도와의 차이가 작아도 지면 오차가 작다는 결론은 나오지 않는다. 이전 **별도의 40경기 시제품**에서 구한 잔차나 미세 정합 수치를 현재 전체 코퍼스의 지형 정확도로 옮겨 쓰지 않는다.

관측 부족·높이 잔차 >5m·수직 변동 >6m·근사 변경 범위·육수 불일치는 진단 규칙이다. 변경 범위는 분석자 지정 원이며 공식 변경 폴리곤이 아니다. 경고가 없는 곳도 버전 일치나 안전한 통행이 확인된 곳은 아니다. 현재 노드의 `exact_patch_match`와 `traversability_verified`는 모두 false다.

40.2는 경기 시작 시각을 공식 점검 구간에 대응시킨 추정이다. 정확한 build 확인이 안 됐고 시작 시각 없는 경기는 이 구간으로 배정하지 않았다. 사용자는 해당 시기의 설치 백업·리플레이가 없다고 밝혔다. 따라서 40.2 원본을 가지고 있다는 가정으로 후속 연구를 설계하지 않는다.

## 4. 논문에 사용할 수 있는 현재 서술

> 본 연구는 정확한 게임 내비게이션 메시를 복원하는 대신, 텔레메트리에서 관측된 이동 전이와 역사적 지도에 기반한 인접 후보를 구분한 100m 공간 표현을 구성하였다. 40.2 추정 구간의 2,675경기를 경기 단위로 분리하고 2,141경기로 지도를 구성하였다. 검증 534경기의 비차량 격자 간 전이 중 99.88%가 학습 관측 엣지에 포함됐으며, 고유 방향 연결 기준 포괄률은 97.98%였다. 이 수치는 관측 이동의 공간적 포괄률이며 지형 정합이나 통행 가능성의 정확도를 나타내지 않는다. 동일 패치의 지형·충돌 정답이 없으므로 역사적 높이의 불일치와 미관측 지역을 명시적으로 보존하였다.

이 문장은 현 분할에 대한 Methods/Data audit 초안이다. 최종 모델 실험의 분할이 바뀌면 수치를 다시 계산한다. 새 모델의 Results가 아니다.

영문 용어는 *telemetry-derived approximate spatial graph*, *observed transition*, *historical adjacency candidate*, *held-out transition coverage*, *descriptive uncertainty flags*를 권장한다. *reconstructed navmesh*, *ground-truth terrain*, *collision-free path*, *calibrated traversability probability*는 현재 증거로 사용할 수 없다.

## 5. 추가 검증 계획: 할 수 있는 것과 못 하는 것

**독립적인 같은 패치 공간 정답을 확보한 경우**에는 원본 출처·빌드를 기록하고, 지도 변경/해안·교량/도시/개활지 등 사전 정의한 층별로 위치·높이·연결을 대조한다. 초기 감사 설계로 셀 120개(4층×30)와 연결 120개를 제안하되 이는 실행·표본 충분성 검증 전의 시작점이다. 주석자는 관측 빈도를 보지 않고 판독하고, 두 명이 가능한/불가능한/판정불가와 이유를 기록한다. 층화 표집이면 전체 비율 추정에 실제 층 가중치를 적용하며 판정불가를 성공으로 넣지 않는다. XY RMSE, 높이 MAE와 분포, 연결 판정의 오류를 각각 보고한다. 아직 이런 결과는 없다.

**현재 버전의 게임 자료만 있는 경우**에는 현재 공간의 국소 대조 또는 패치 이동 실험으로 명명한다. 문서상 변경 없음만으로 40.2와 동일함을 인증할 수 없다. 현재 게임에서 가능한 경로를 과거 40.2의 정답으로 쓰지 않는다. 같은 패치 독립 정답이 없으면 역사적 지형·충돌 정확도는 계속 미확인으로 남긴다.

원본 없이도 다음은 가능하다.

1. 학습 경기 bootstrap/subsample마다 엣지 존속률·노드 고도 요약·경고 안정성을 측정한다. 이는 표본 안정성이지 정확도는 아니다.
2. 경기·시간 보류, 공간 block 보류를 구분한다. 공간 보류에서는 해당 block과 경계 이동을 학습 그래프/사전학습에서 제거하고 crossing 처리 규칙을 먼저 정한다. 결과는 미관측 구역 일반화이며 지형 정답 검증은 아니다.
3. 50/100/200m 재구성, XY ±10/25/50m 교란, 높이 ±5/10m 교란, 관측 엣지 삭제 10/30/50%, 추정 엣지 제거를 통해 모델 성능 민감도를 측정한다. 이 수치들은 스트레스 테스트 수준이지 실제 지도 오차 추정값이 아니다.
4. 공간 없음/노드 특징만/관측 엣지만/추정 포함/불확실성 포함 모델을 비교한다. 좋은 생성 성능은 표현의 유용성을 지지하지만 절대적 지형 정확도를 입증하지 않는다.
5. 인간/봇·일반/경쟁/AI Royale·고지지/저지지·변경 경고 구역을 분리한다. 전체 평균을 세부 집단의 보장으로 사용하지 않는다.

## 6. FDG 논문화의 중심과 미확정 사항

현재 가능한 연구 질문은 **부정확성과 출처가 다른 공간 근거를 구분해 넣으면, 공개 안전구역에 조건화된 거시 경로 생성과 인간·봇 행동 비교가 얼마나 개선되는가**다. 정확한 PUBG 지도 복원 자체를 주된 기여로 삼기에는 정답 자료가 부족하다.

현재 validation은 이미 지도 포괄률을 확인했다. 추후 모델의 pristine test라고 부르지 않는다. 재분할 때는 그래프·오프셋·사전학습을 분할마다 재생성하고, 전체 코퍼스의 사전 탐색을 수행했다는 점을 공개한다. 학습 corpus 전체의 공간 통계라도 평가 경기에서 유래한 값은 모델의 입력으로 쓰지 않는다.

인간/봇 라벨은 account./ai. 규칙이며, 관측 비교는 인과효과가 아니다. 인간형 경로의 개선을 봇 실제 미래에 대한 ADE 하나로 판단하지 않는다. 동일 상태에 가까운 인간 분포, 후보 다양성, 공개 구역 대응과 거시적 운동 제약을 함께 평가한다. 승률·생존 향상과 인간 평가자가 느끼는 인간다움은 별도 실험 없이는 주장하지 않는다.

진행 상태: 공간 산출물·코드/수량 검사는 완료. 공간 정답 검증, 구역 raw 의미 감사, 학습 창 구축, GNN/Diffusion 학습, 인간·봇 비교 결과, 최종 문헌 신규성 검토는 미완료다. 후속 상세 설계는 [graph-zone diffusion v2](../experiment_design/ERANGEL_GRAPH_CONDITIONED_DIFFUSION_DESIGN_2026-10-15.md)에 있다.
