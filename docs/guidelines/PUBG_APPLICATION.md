**수업 논문 → FDG 2027을 유지하고 ToG는 후속 확장으로 둔다.**

2026-10-20 저자에게 H1과 기존 PUBG 계획의 차이를 확인했고 위 답변을 받았다. 현재 PUBG의 H1·H2 적용은 이 답변을 따른다. 원문의 LoL 교전 과정 모형 C(B7), CoG #308 확장 계획(H2), 기존 ToG 원고 관계가 PUBG의 연구 과제로 자동 확정된 것은 아니다. 현재 승인된 연구 맥락은 공간·경기 구조의 사전학습과 개인·팀 이종 그래프, 안전구역 조건부 경로 생성이다. B7의 큰 그림 우선·세부 설계 승인·긴 실행 전 설계 완료 절차는 따른다.

## 바로 적용할 공통 규칙

근거를 갖춘 설계, 설계·패치 사전 제시와 승인, 단계별 보고, 읽기 전용 원천 DB, 비밀 보호, 분할 누수 방지, 평가 사전 등록, 수학 검산, 자원 측정, 재현성, 증거 사슬 보존, 문헌 식별자 검증, 코드 내 문헌 근거, 지침 충돌 시 논의를 적용한다.

새로운 설계·구현·학습은 현재 승인 범위를 확인하고 진행한다. 이 지침을 저장하고 에이전트 진입 문서에 연결하는 작업은 이번 저자 요청에 직접 포함된다. 이 채택 작업은 새로운 모델 코드 수정·학습·설치·커밋·푸시의 승인이 아니다.

원문의 `[해석]`은 그대로 제안 상태로 남긴다. 새 논의 없이 과거의 특정 실험 승인이나 설치 목록 승인을 이번 프로젝트의 별도 실행 권한으로 확대하지 않는다.

## 경로와 보존

- 원문 `D:\LOL_*`, `C:\Users\todtj\...`, r1/r2 전달 폴더와 CARD는 다른 작업 환경의 참조다. 이 Mac에 같은 경로를 만들거나 기존 PUBG 파일을 그 위치로 이동하지 않는다.
- 기존 PUBG 산출물은 현재 위치를 보존한다. 새 대용량 산출물을 저장소 밖에 두는 정책(I1)의 실제 대상 경로가 필요해지면 경로·용량·보존 범위를 제시해 확인한다. 이번 채택으로 기존 증거 파일을 이동·삭제하지 않는다.
- 기존 품질 점검은 [품질 인덱스](../data_layer/CORPUS_QUALITY_INDEX.md)를 참조한다. 원천 PostgreSQL을 수정하지 않고 로컬 SQLite 색인을 사용한 기록이다.
- 새 규칙 이후 완료된 실행의 결과는 동결하고 재분류·수정 실행은 별도 버전으로 기록한다. 현재 품질 인덱스 도구가 고정 경로에 결과를 쓰는 구조는 후속 실행 전에 변경 설계를 제시할 대상이다.
- 기존 테스트 보호 집합과 노출 이력은 유지한다. 보호 여부 확인을 위해 분할 모듈의 본문이나 소금을 열어보지 않는다.

## 장치·도구·환경

### 2026-10-20 후속 진행과 자기 피드백

직전 설계 보고 뒤 저자가 “그래 이제 더 진행해봐 자기 피드백을 반복하면서”라고 지시했다.
앞 절의 설계 전용 범위는 당시 기록으로 보존하고, 이번에는
[G1 구현 계획](../experiment_design/WORLD_MODEL_G1_IMPLEMENTATION_2026-10-20.md)에 제시한
입력 어댑터·인코더·반증 시험·CPU 순전파/gradient 연결 확인까지 진행한다.
가중치 갱신이나 긴 학습은 이 단계에 포함하지 않는다.
자체 피드백의 발견과 수정 근거를 새 보고서에 남긴다.

- CPU 보고용/GPU 탐색용(A6a), private memory 48 GiB 상한(A6)은 지침으로 유지한다. 원문의 RTX 5080·Windows·고정 패키지 버전이 현재 호스트에 설치됐다고 가정하지 않는다. 실행 전에 실제 환경과 결정성을 확인하고, 지침을 충족하지 못하면 실행에 앞서 논의한다.
- graphify, Strata, eli5-design-memo 등의 원문 설치 이력은 이 세션의 사용 가능성을 증명하지 않는다. 관련 작업 때 스킬·도구를 확인하고, 없다면 누락과 대안을 설명한다. 설치는 E3–E5의 범위를 따른다.
- I12의 Sonnet/Haiku 구현·Opus 검토는 선호하는 역할 분담으로 보존한다. 현재 Codex 하위 에이전트 인터페이스에는 해당 모델 선택지가 없으므로 이 방식으로 실행했다고 주장하지 않는다. 실제 위임이 필요하면 지원 가능한 연결이나 대안을 먼저 논의한다.
- 현재 학습 환경에 임의 패키지를 설치하지 않는다. 별도 환경의 위치·잠금·시험을 정하고, 참조 코드 실행 제한과 라이선스 검토를 따른다.
- Strata·llama가 실행 자원을 점유하는지 긴 실행 전에 확인한다. 사용자 허락 없이 다른 프로세스를 종료하지 않는다.
