# G4 사전등록 보완 v2 — 미학습 이진 flag의 임의 효과 제거

개발 성능 집계 전, 입력 지원과 초기화 코드 점검에서 발견.
원래 프로토콜의 표본·혼합비·seed·예산·지표·판정 기준은 그대로 둔다.
prepared_01 텐서와 역할 경계도 동일하다.

현재 실제 fit corpus는 40.2뿐이다. known_change와 geometry_verified가 모두 0이므로
해당 두 feature의 support/gate 계수는 학습할 수 없다.
기존 랜덤 초기화 계수를 41.1의 known_change=1에 곱하면 학습되지 않은 반응이 생긴다.
두 열을 0으로 초기화하고 0 입력에서 그대로 유지되는지를 시험한다.
출처·age·관측량·이동 mode는 그대로 사용한다.
이 보완은 지형 변화 대응을 학습했다는 주장을 추가하지 않는다.

seed_*_01 결과는 보존하고 주 비교에서 제외한다.
보완 실행은 seed_*_02, 별도 프로세스 재현은 seed_20261020_repeat_02.
이 변경은 개발 성능을 보고 선택하지 않았으며 동일한 3개 seed를 모두 다시 실행한다.
첫 v1 seed 둘은 실행 구간이 일부 겹쳤으므로 v1 시간은 장치 성능 근거로 사용하지 않는다.
v2는 전체 순차 실행한다.
