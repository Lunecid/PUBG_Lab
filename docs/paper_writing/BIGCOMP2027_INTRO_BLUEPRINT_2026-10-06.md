# 서론 설계도: 사용자 확정 흐름 (2026-10-06)

- **작성 방식**: 사용자가 문장을 쓰고, Claude가 설계와 검토를 맡는다. 문장은 영어로 직접 쓴다.
- **흐름 (사용자 확정)**: 맥락 → 수단(PUBG) → 과제 → 난점 → 현실 세계의 해법(서식지 생태학) → 수단에 적용 → RQ
- **선행 설계의 위치**: RQ2와 RQ3가 선행 연구를 언급하므로, 선행 설계는 RQ보다 먼저 ④ 난점에서 소개한다. 상세한 관련연구는 Section II로 보낸다.

## 단락 구성 (4단락 + 기여, 약 550–700단어)

| 단락 | 담당 흐름 | 분량 |
|---|---|---|
| P1 | ① 맥락 + ② 수단 | 130–170단어 |
| P2 | ③ 과제 + ④ 난점 | 130–170단어 |
| P3 | ⑤ 현실 세계 + ⑥ 적용 | 120–160단어 |
| P4 | ⑦ RQ + 접근 + 기여 목록 | 150–200단어 |

## 흐름별 설계

### ① 맥락 (1–2문장)
- **할 일**: 가용 영역이 변하는 환경에서 다중 에이전트 시스템이 대규모 시공간 telemetry를 만든다는 점을 제시한다.
- **넣을 요소**: 분야 예시 2–3개, 로그의 구성(위치 시계열, 상호작용, 환경 변화), 서베이 인용 2개(검증 중).

### ② 수단: PUBG (2–3문장)
- **할 일**: PUBG를 이 맥락을 대규모로 관측하고 반복 실험할 수 있는 장으로 소개한다.
- **넣을 요소**:
  - 게임 규칙: 최대 100명, 1·2·4인 팀, 마지막 팀이 승리한다.
  - 안전구역이 단계마다 줄고 밖에서는 피해를 입는다. 이 안전구역이 ①의 가용 영역에 해당한다.
  - 공개 telemetry: 모든 플레이어의 위치가 10초 간격으로 기록되고, 교전·아이템·구역 이벤트가 함께 남는다.
  - 같은 규칙으로 경기가 반복되며, 맵과 모드가 다양하다.
- **선택**: 이 해상도의 경기 내 로그는 공개된 형태로 드물다는 한 구절. 상세 근거는 Section III에 둔다.

### ③ 과제 (1–2문장)
- **할 일**: 예측 대상을 정의하고, 왜 이 대상인지 밝힌다.
- **넣을 요소**:
  - 결정은 단계마다 내려진다.
  - 예측 대상은 각 단계 경계에서 각 팀이 다음 단계 안에 탈락할 확률, 곧 next-phase elimination risk다.
  - 쓰임: 경기 중 판단, 중계, 단계별 압박 설계.
  - 경기 단위 우승확률과의 차이: 사전값이 1/N이고, 당장의 위험과 장기적 강함을 한 수에 섞는다.

### ④ 난점 (2–4문장)
- **할 일**: 이 과제가 왜 어렵고, 기존 설계가 왜 답을 주지 못하는지 밝힌다.
- **넣을 요소**:
  - 본질적 난점: 위험은 줄어드는 영역의 기하와 경쟁 팀의 상호작용에 함께 달려 있고, 단계마다 달라진다.
  - 데이터 난점(수치 없이): 기록이 불규칙하고 비동기적이다. 기절과 탈락을 구분해야 한다. 단계 경계를 넘는 정보는 결과를 누설한다.
  - 선행 설계:
    - Sagong et al.: 플레이어 단위, 반 단계 생존 분류, 활동 점수, 100 m 안 인원수.
    - KRAFTON: 팀 간 transformer, Cox 사망 시각 순위를 우승확률로 변환, 단계는 표본 추출에만 사용.
    - Cox는 한 시점의 모든 점수를 같은 값만큼 옮겨도 결과가 같다. 그래서 단계 사이의 위험 상승을 표현하지 못한다.
  - 마무리: 두 설계는 단위, 데이터, 지표가 서로 달라 어떤 설계 선택이 성능을 좌우하는지 알 수 없다.

### ⑤ 현실 세계의 해법 (2문장)
- **할 일**: 생태학이 같은 구조, 즉 서식지가 줄어들 때의 생존을 다뤄 왔음을 보인다.
- **넣을 요소** (모두 서지 검증 완료):
  - 서식지 손실은 크고 일관된 부정적 효과를 낸다 [Fahrig03].
  - 메타개체군 모델은 국지 지속을 패치 면적과 고립도에 연결한다 [Hanski94].
  - occupancy 모델은 기간별 국지 멸종 확률을 추정한다 [MacKenzie03].
  - (선택) 이동 생태학은 분산 비용을 다룬다 [Nathan08].

### ⑥ 수단에 적용 (2–3문장)
- **할 일**: 생태학의 틀을 PUBG에 대응시키고, 그로부터 나오는 설계를 제시한다.
- **넣을 요소**:
  - 대응: 안전구역 축소는 단편화 없는 단계적 서식지 손실이고, 팀 탈락은 국지 멸종이며, 단계는 손실의 한 단계다.
  - 정식화: 단계 조건부 이산시간 국지 멸종 hazard.
  - 표현: 팀의 서식지 맥락. 가장자리 노출, 분산 요구, 국지 밀집, 개체군 크기다.
  - 선행 설계와의 대비: 추정 대상과 표현이 다르다.
- **쓰지 않을 것**: 수치. 결과는 P4의 기여 목록에서만 미리 보여준다.

### ⑦ RQ와 접근 (P4)
- **전환 문장**: "This view raises three questions."
- **RQ** (사용자 설계를 영문으로):
  - RQ1: Can next-phase elimination be related to the habitat-loss mechanism through ecological modeling, unlike prior approaches?
  - RQ2: If so, what model design does this imply relative to prior designs, and does it change predictive performance?
  - RQ3: If performance differs, which design element contributes most when the difference is decomposed?
- **접근**: 공개 13,948경기, 12개 코호트, 사건 기반 라벨, 누수 없는 파이프라인. 두 선행 설계를 같은 표본에 적용하고, 한 번에 한 요인만 바꿔 분해한다.
- **기여 목록**: 3–4개 항목, 수치 미리보기 포함. 근거는 `BIGCOMP2027_RQ_CLAIM_BLUEPRINT_2026-10-06.md`를 따른다.
