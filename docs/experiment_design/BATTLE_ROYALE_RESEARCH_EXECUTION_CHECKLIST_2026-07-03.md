## Purpose

This document is the working checklist for the Battle Royale framework paper.
It tracks what has been completed, what remains, which methodology was applied,
and what concrete artifact should exist after each step.

The current state is post-ontology-lock, post-formalization,
post-ontology-validation-protocol, post analytic-framework claim-boundary
decision, post required-cohort OM ladder first run, post phase-stratified
OM mechanism analysis, post O1 survival-capital integrity audit, and post
phase-group paired bootstrap uncertainty check, corrected O6 Z-ladder
sensitivity protocol, Z1-Z3 feature availability audit, O6 Z-affordance
ETL/tensor mapping, corrected OM6Z required-cohort run, gen-1/gen-2
result-boundary audit, short O7 edge-shuffle/cache-run smoke, four-cohort O7
early readout, full 13-cohort O7 hazard-AUC readout, and hazard-implied O7 rank
bridge. The paper spine is now fixed as RQ1 Battle Royale formalization, RQ2
PUBG official-telemetry representation as the representative game case, RQ3
prior tabular / phase-aware prediction plus 10-second realtime
elimination-risk model development, and RQ4 phase-transition most-at-risk /
most-advantaged team prediction. Warzone / Caldera is now supplementary
observability and future O6 terrain-boundary evidence, not a core RQ. O7 is
supplementary null-control evidence, not the core path. The next major work is
manuscript figure/prose assembly around this revised canonical flow, plus
explicit board-baseline comparison for the RQ4 risk/advantage board.

## Update Rule

Before starting a major new work item, add or confirm the checklist row for that
item. After completing it, update:

1. `Status`
2. `Progress / Finding`
3. `Method Applied`
4. `Artifact / Evidence`
5. `Next Action`

This file is the operational progress board. Design details stay in their owning
package docs.
