# Final Experiment Code Design

This document defines the final experiment rewrite without invalidating the
legacy results already produced by `model_stgcn`.

## Principle

The previous pipeline proved that the input representation is meaningful. The
final pipeline must test the stronger claim: the correct input unit matters.

The paper claim should remain representation-first:

```text
Factorized multi-resolution representations preserve PUBG survival hazard and
final ranking structure better than flat/raw or broadcast-only representations.
```

The final model is an implementation of this claim, not the claim itself.

Therefore V3 separates:

- `X_node`: team/node features
- `G`: global phase context
- `A`: dynamic team graph
- `X_s`, `A_s`: optional 10-second snapshot tier
- labels: never used as input

## New Package

`model_stgcn/v3/`

| File | Responsibility |
| --- | --- |
| `spec.py` | declares feature roles: node vs global |
| `factorized_data.py` | converts existing phase/MR tensors into `X_node`, `G`, `A` |
| `models.py` | factorized GNNs with pluggable graph encoders and global fusion |
| `train.py` | trains phase or MR factorized models |
| `eval.py` | evaluates hazard, rank, top-k, and calibration on identical splits |
| `experiment_matrix.py` | canonical final experiment matrix |

## Input Contract

The old phase tensor was:

```text
X_legacy[k, i] = [global phase context broadcast to team i ; node/team features]
```

The V3 tensor is:

```text
X_node[k, i] = team-specific state, movement, combat, loot, network role, local habitat pressure
G[k]         = phase/global context, shrinking-zone state, global habitat pressure
A[k]         = proximity/combat/copressure graph
```

The current graph channels remain:

- `proximity`
- `combat`
- `copressure`

## Model Families

The final phase model is:

```text
X_node -> node encoder
G      -> global encoder
A      -> graph encoder
fused hidden sequence -> causal temporal blocks -> task decoders
```

Supported graph encoders:

- `none`
- `gcn`
- `sage`
- `gat`
- `rgcn`

Supported global fusion modes:

- `none`
- `concat`
- `add`
- `film`

Supported team decoders:

- `mlp`: per-team output heads, matching the legacy head design
- `attention`: self-attention over the team set before final rank/top-k heads

The main hazard head remains phase-local and causal. Final rank and top-k heads
can optionally use the team-set attention decoder because final standing is a
relative match-level outcome.

The final MR model adds:

```text
X_s, A_s -> snapshot encoder -> phase-local pooling -> concat to X_node
```

## Multi-Task Labels

V3 keeps next-phase elimination hazard as the main endpoint, but supports
parallel supervision:

| Head | Target | Role |
| --- | --- | --- |
| hazard | next-phase elimination | main survival endpoint |
| rank | normalized final rank | final ordering auxiliary |
| top-k | top5/top10 | final survival bracket auxiliary |
| snapshot survival | near-future death at 10s resolution | MR deep supervision |
| pairwise rank | pairwise final ordering | optional listwise-style ranking signal |

The loss is:

```text
L = alpha * hazard_BCE
  + beta  * rank_MAE
  + gamma * topk_BCE
  + delta * snapshot_survival_BCE
  + eta   * pairwise_rank_loss
```

`eta=0` recovers the legacy multi-head setup. `eta>0` enables whole-rank
ordering supervision.

## Evaluation Unit

The evaluation unit is fixed before model comparison:

| Item | Protocol |
| --- | --- |
| hazard target | next-phase team elimination |
| hazard risk set | teams alive at the cut phase with a defined next phase |
| hazard loss/eval | masked by `target_mask` only |
| rank target | normalized final rank |
| rank evaluation | report alive-only rank metrics by phase band; all-team rank is secondary |
| split | match-level split |
| phase definition | safe-zone phase-aligned intervals |
| snapshot tier | 10-second team snapshots mapped back into phase bins |

This prevents already-eliminated teams or undefined final phases from inflating
hazard or rank metrics.

## Canonical Final Matrix

The minimum final matrix is generated by:

```bash
python3 -m model_stgcn.v3.experiment_matrix
```

The intended interpretation:

1. `main`: all neural architecture comparisons use MR input for fairness.
2. `resolution`: phase-only models are used only to quantify the value of MR.
3. `decoder`: attention rank decoder and pairwise rank loss are component ablations.
4. `graph_control`: graph channels are ablated separately from the architecture table.

The main architecture table is intentionally small:

| ID | Meaning |
| --- | --- |
| `mr_tcn` | MR input without graph |
| `mr_gcn` | simple graph convolution |
| `mr_sage` | GraphSAGE-style aggregation |
| `mr_gat` | graph attention |
| `mr_rgcn` | relation-aware graph convolution |
| `mr_rgcn_film` | global FiLM conditioning |
| `mr_rgcn_attn_rank` | attention rank decoder |
| `mr_farnet` | final candidate: MR + R-GCN + FiLM + AttnRank |

## Baselines

The final paper must retain strong non-GNN baselines:

| Baseline | Purpose |
| --- | --- |
| logistic regression | weak linear reference |
| HGB/LightGBM/XGBoost | strong tabular reference |
| Phase-TCN | non-graph phase neural baseline |
| MR-TCN | non-graph MR neural baseline |

GNN comparisons are only convincing if they beat or complement the strong
tabular baseline under the same split and risk cells.

## Paper Tables

Recommended compression:

| Table | Content |
| --- | --- |
| Main result | strong baselines vs MR-GCN/MR-RGCN/MR-FARNet |
| Representation ablation | raw, node, node+global, habitat/network/STDB, graph, MR |
| Controls | observed graph vs shuffled/random graph; ordered vs time-shuffled snapshots |
| Task-wise evaluation | hazard, rank, top-k, calibration |

## Legacy Compatibility

The old modules remain untouched as reproducibility baselines:

- `model_stgcn.train_phase`
- `model_stgcn.eval_phase`
- `model_stgcn.train_mr`
- `model_stgcn.eval_mr`
- `model_stgcn.feature_ablation`

V3 is a parallel final-experiment layer, not a destructive rewrite.
