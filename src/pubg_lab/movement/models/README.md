# pubg_lab.movement.models

Model architectures and reusable components.

| Component | Purpose |
|---|---|
| `model.py` | Joint, member-equivariant graph-conditioned residual diffusion (v prediction). |
| `model_v3.py` | Same-input joint regression and smooth-knot diffusion with direct circle conditioning. |
| `model_v4.py` | Team-center/relative-formation prediction and frozen-mean residual diffusion. |

Import the canonical module path. `python -m pubg_lab list` lists explicit commands without executing them.
Research inputs, completed evidence, and access restrictions follow the repository guidelines.
