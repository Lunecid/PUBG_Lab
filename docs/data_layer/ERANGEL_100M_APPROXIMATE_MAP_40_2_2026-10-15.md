## 1. 모집단과 경기 분리

DB의 `pubg.matches`와 `pubg.telem_match_start`를 연결해 Steam, `Baltic_Main` 또는 `Erangel_Main`, 시작 시각 `2026-03-11 08:30 UTC ≤ t < 2026-04-08 00:00 UTC`를 선택했다. 이번 대상은 모두 `Baltic_Main`이고 이벤트 모드는 false다. 실제 관측 경기의 시작 시각은 2026-03-25 23:58:14.120 UTC부터 2026-04-07 23:18:02.193 UTC까지다. 한국 시각으로 3월 26일 08:58부터 4월 8일 08:18까지다.

40.2는 **시작 시각으로 추정한 공개 패치 구간**이다. DB에 정확한 build 필드가 없으므로 핫픽스까지 확인한 같은 빌드 집합이라고 주장하지 않는다. 이전 전체 Erangel 목록의 시작 시각 없는 269경기는 패치를 배정할 수 없어 포함하지 않았다. 이 문서에서 ‘전체’는 DB에서 위 조건으로 식별 가능한 2,675경기 전체라는 뜻이다. 기존 40경기 시제품에서 자료를 재표집한 결과가 아니다.

참가자 목록에 존재하고, 계정별 착지 이후·첫 기록된 사망 이전이며, `health > 0`, 유효 XYZ, 같은 계정·시각에 중복 없음, `0 ≤ x,y < 816000 cm`인 위치를 유지한다. 첫 사망 이후 부활한 궤적은 이번 정의에서 제외된다. `account.`는 인간 후보, `ai.`는 봇 후보로 구분한다. 사람·봇은 독립적으로 확정된 정답 라벨이 아니라 식별자 규칙이다. AI Royale이라는 경기 유형 자체를 봇 라벨로 사용하지 않는다.

차량 ID 또는 유형이 기록되면 차량 레이어로 분리한다. 기록이 없는 상태를 비차량이라고 부르며, 도보나 지면 접촉이 인증된 상태로 취급하지 않는다. 수영·점프 등과 샘플 사이의 상태 변화는 남을 수 있다.

같은 계정의 인접한 원시 행 사이에서 필터를 통과한 두 위치만 연결한다. 제외된 중간 행이 있으면 연결을 끊는다. 시간 간격은 5–15초, 수평 평균속도는 비차량 12m/s 이하·차량 90m/s 이하이며, 양 끝의 차량 기록 상태가 같아야 한다. 샘플 사이를 보간하지 않는다. 이 조건의 모든 유지 연결은 12,938,025건, 서로 다른 격자를 잇는 연결은 3,774,576건이다. 같은 격자에 머문 연결은 엣지 파일에서 제외하고 위치 관측량에는 남긴다.

학습 비차량 위치는 **9,901,068개**, 검증 비차량 위치는 **2,476,060개**다. 차량 위치도 전체 처리했으며 학습 차량 위치 1,040,781개에서 별도 차량 그래프를 구성했다.

## 3. 격자와 두 연결 유형

좌표는 cm를 m로 나누고, 원점 좌상단·x 오른쪽·y 아래쪽으로 둔다. 범위는 8,160m × 8,160m다. `cell_x = floor(x_m/100)`, `cell_y = floor(y_m/100)`, `node_id = cell_y × 82 + cell_x`이다. **82 × 82 = 6,724개 격자**이며 오른쪽·아래쪽 마지막 격자 폭은 60m다.

| 전체 격자 | 6,724 | 고정 좌표 범위 | 바다·미관측 포함 |
| 비차량 관측 격자 | 4,163 | 학습 위치 1개 이상 | 수면 위 관측도 포함 |

| 3경기 이상 지지된 관측 방향 연결 | 23,609 | 독립 경기 수 기준 | 기본 시각화에 표시 |

과거 높이 영상의 격자 내부 4×4 표본 중 raw height ≥32768인 비율을 `historical_land_fraction`으로 둔다. 이 비율이 0.75 이상인 3,026개를 육지 후보로 정했다. 현재 해안선의 정답 분류가 아니다. 후보 격자끼리 상하좌우로 붙어 있고 그 방향의 관측 엣지가 없을 때만 추정 엣지를 추가했다. 관측·추정 엣지는 동일한 방향 쌍을 공유하지 않는다. 사선 인접이나 임의의 최단 경로로 미관측 구역을 채우지 않았다.

관측 연결도 100m 셀 안의 정확한 진입·출구를 알려주지 않는다. 화면에 그린 선은 격자 중심의 연결이다. 서로 다른 사람의 전이를 이어 붙인 그래프 경로가 실제로 연속 통행 가능하다는 보장도 없다. 추정 연결에는 역사적 높이 차이/중심 거리 값을 저장하되, 검증되지 않은 경사 임계값으로 길을 확정하거나 막지 않았다.

## 4. 높이와 불확실성

2019 높이 영상은 `(raw − 32768)/128`을 고정된 높이 근사값으로 사용했다. 이전 40경기 시제품에서 얻은 학습된 스케일·수평 보정값은 재사용하지 않았다. 현재 학습 경기만으로 플레이어 고도와 높이 근사값의 차이에 대한 오프셋 **0.90254m**를 계산했다. 보정에는 987개 격자가 사용됐다. 지지 10경기 이상, 육지 비율 ≥0.75, RGB 수면 후보 비율 <0.25, 알려진 변경 근사 범위 밖, 수직 변동 요약 ≤3m인 격자다.

관측 고도 요약은 전체 원시 점을 합친 중앙값이 아니다. 먼저 경기·격자·플레이어 종류별 중앙값과 10/90 분위수를 계산하고, 경기·격자 안에서 종류별 중앙값의 중앙값을 구한 뒤, 경기 사이 중앙값을 구했다. 경기·격자가 같은 가중치를 갖도록 했다. 수직 변동은 경기·격자 안에서 종류별 Q90의 최댓값 − Q10의 최솟값을 구한 후 경기 사이 중앙값이다. 잔차도 실제 위치에서 샘플링한 과거 높이와의 차이를 같은 방식으로 요약했다.

| 경고 코드 | 기준 | 전체 격자에서 해당 수 |
|---|---|---:|
| `unobserved` | 학습 비차량 관측 0경기 | 2,561 |
| `low_match_support` | 학습 비차량 관측 1–9경기 | 640 |
| `height_disagreement` | 보정 후 높이 잔차 요약의 절댓값 >5m | 639 |

| `known_change_buffer` | 이전 변경 이력으로 지정한 근사 원형 범위 | 1,349 |
| `land_water_disagreement` | 높이와 RGB 휴리스틱의 강한 육수 불일치 | 79 |
| `coastal_mixed_cell` | 육지 표본 비율 0.25 초과 0.75 미만 | 286 |
| `observed_over_water_prior` | 관측이 있으나 과거 육지 비율 <0.25 | 816 |

경고는 중복될 수 있다. RGB 수면 후보는 1024px로 줄인 공식 이미지에서 `B > 1.25R AND G > 1.3R`인 격자 내부 표본의 비율이다. 육수 불일치는 육지 비율 ≥0.75이고 RGB 수면 비율 ≥0.75이거나, 두 비율이 모두 ≤0.25인 경우다. 이는 지형 분류기의 검증된 출력이 아니다.

화면 색은 미관측 → 관측 1–9경기 → 10경기 이상이면서 추가 경고 있음 → 10경기 이상이고 추가 경고 없음 순으로 배정한다. 따라서 저관측 셀에 높이 경고가 동시에 있어도 노란색을 유지하며, 상세 정보에 모든 경고를 표시한다.

| 과거 육지 후보만의 분류 | 격자 수 |
|---|---:|
| 10경기 이상, 추가 경고 없음 | 1,540 |
| 10경기 이상, 추가 경고 있음 | 1,403 |
| 1–9경기 관측 | 77 |
| 미관측 | **6** |
| 합계 | 3,026 |

육지 후보의 99.80%가 관측됐고 97.26%가 10경기 이상 지지됐다. 반면 반복 관측된 육지 후보 중에도 1,403개는 추가 경고가 있다. **관측이 충분함과 공간 구조가 정확함은 다른 문제다.** 높이 경고는 지형 변경뿐 아니라 건물 층, 교량, 이동 상태나 수평 표본 위치의 차이에서도 생길 수 있다.

변경 범위는 이전 조사에서 지명 중심과 근사 반경으로 설정한 분석자 정의 원이다. 공식 변경 폴리곤도 완전한 변경 목록도 아니다. 원 밖이 바뀌지 않았다는 뜻은 아니다. 모든 노드에 `exact_patch_match=false`, `traversability_verified=false`를 명시했다. 불확실성 임계값은 이번 시제품의 진단 규칙이며 보정된 확률이 아니다.

## 5. 검증 경기에서 확인한 범위

학습 그래프를 JSON으로 저장하고 SHA-256을 계산한 뒤 검증 캐시를 읽었다. 검증이 끝난 뒤 해시가 같음을 확인했다. 새 검증 연결을 관측 그래프에 추가하지 않았다.

| 지표 | 결과 |
|---|---:|
| 검증 비차량 위치 | 2,476,060개 |
| 학습에서 관측한 격자에 속한 검증 위치 | 2,475,751개 / **99.9875%** |
| 검증 비차량 비자기 전이 | 568,999건 |
| 학습 관측 연결에 포함 | 568,342건 / **99.8845%** |
| 추정 연결에만 포함 | 44건 / 0.0077% |
| 두 연결 유형에 모두 없음 | 613건 / 0.1077% |
| 경기별 관측 연결 포함률의 단순 평균 | **99.8836%** |
| 검증의 고유 방향 연결 수 | 23,566개 |
| 고유 연결 중 학습 관측 연결에 포함 | 23,090개 / **97.9801%** |
| 고유 연결 중 추정 연결에만 포함 / 미포함 | 30개 / 446개 |

전이 횟수 가중 비율 99.88%와 고유 연결 기준 97.98%를 함께 제시한다. 반복되는 흔한 이동이 전체 전이 비율을 높이기 때문이다. 관측 연결이 없다는 것은 통행 불가능하다는 증거가 아니며, 추정 연결에 검증 관측이 없다는 것도 오류라는 증거가 아니다.

일반 경기의 전이 포함률은 99.8684%, 경쟁 99.8958%, AI Royale 99.8997%다. 인간 후보 전이는 99.8613%, 봇 후보 전이는 99.9008%였다. 서로 같은 경기 구성을 통제한 차이가 아니므로 인간·봇의 이동 품질 차이로 해석하지 않는다. AI Royale을 포함해 만든 공동 지도의 포괄률이며, AI Royale을 배제해도 같은 결과가 나오는지는 별도 검증이 필요하다.

## 7. 다음 연구 단계에 연결하는 방법

이 자료는 100m 수준의 이동 경로를 생성하는 모델의 공간 조건으로 사용할 수 있다. 관측 엣지와 추정 엣지는 서로 다른 관계로 인코딩하고, 노드의 관측 지지·경고를 함께 입력한다. 고도는 역사적 근사값과 플레이어 관측 요약을 분리하고, 미관측 값을 0m 지면으로 대체하지 않는다. 알려진 변경 지역에서는 과거 높이에 대한 의존도를 낮추는 실험이 필요하다.

안전구역은 정적 공간 그래프에 섞지 않고 시각별 조건으로 붙인다. 입력 시점에 알려진 안전구역만 사용하고, 이 그래프에 검증 미래 이동을 추가하지 않는다. 우선 격자 시퀀스 또는 큰 방향의 경로를 생성하는 과제로 시작할 수 있다. 건물 문·실내 층·교량 보행로를 통과하는 수m 단위 경로와 충돌 없는 이동은 이 해상도의 검증 범위를 벗어난다.
