# BigComp 2027 방어·대비 강화 계획

작성: 2026-10-07. 수치는 모두 v2 재실행 결과다(`reports/bigcomp2027_results_v2/`, `reports/krafton_baseline_v2/`).

## 0. 결정 (사용자, 2026-10-07)

- 논문의 정체성은 "선행연구를 이기는 방법"이 아니다. 줄어드는 구역 아래에서 단계별 탈락 위험을 무엇이 좌우하는지(정식화, 맥락, 구조)를 통제 비교로 밝히는 분석 연구다. 선행 설계보다 나은 결과는 근거로 쓰며, 기여 자체로 내세우지 않는다.
- 대비의 중심은 AUC 차이가 아니다. 추정 대상의 차이가 결과로 드러나는 지점, 즉 단계별 위험 수준을 중심에 둔다.
- 예상 공격마다 방어 근거를 원고에 미리 배치한다.

- 결과 장의 서술 순서(RQ1 → RQ2 → RQ3)를 따른다.

  - 그림 3 = D1 + D2(RQ2·RQ3)
- 그림 안에는 해독할 수 없는 수식을 두지 않는다. 기호의 뜻은 캡션에서 밝힌다.
