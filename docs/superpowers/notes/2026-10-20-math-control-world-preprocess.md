# 전처리 검산: 단위, 관측 시각, 팀 관계, 결과 라벨

실행: 저장소 루트에서 `python3 -m tools.world_model_toy_checks`.
이 노트는 모델 학습이나 성능 검증 결과가 아니다.

1. **단위**: 좌표 `(20100, 9900)`cm는 `(201,99)`m다.
   100m 셀 키는 각 좌표를 100으로 나눈 뒤 내림한 `(2,0)`이다.
   맵·추정 패치는 셀 키의 상위 키이며 다른 패치의 같은 정수 셀을 하나로 합치지 않는다.
2. **as-of 선택**: 관측 시각이 98, 108.2, 115초이고 예측 시각이 110초면
   108.2초를 고른다. 관측 나이는 1.8초다. 더 가까워 보여도 미래 관측을 입력으로 쓰지 않는다.
3. **팀 거리**: 두 팀원의 상대 변위가 `(3,1)`m면 거리는 `sqrt(10) ≈ 3.16227766`m다.
   팀 중심만 맞춰서는 이 거리를 보장하지 못한다. 구현 시험에도 같은 값을 사용했다.
4. **팀 순위**: 재진입을 포함한 최종 탈락 순서가 완전히 확인되고 동률이 없는 4팀 경기라면
   첫·둘째·셋째 탈락은 4·3·2위, 마지막 생존 팀은 1위다.
   `rank = N - elimination_index + 1`이며 수학적 역수 `1/e`가 아니다.
   현재 원천에서 최종 탈락을 항상 증명할 수 없어 마지막 사망 시각을 확정 정답으로 쓰지 않는다.
5. **패치 경계**: 한국 시간 2026-04-08 08:59:59는 40.2 일정 안이다.
   09:00:00부터 점검 시작이므로 40.2나 41.1로 강제 배정하지 않는다.

직접 확인: 110초 예측에 115초 관측을 넣으면 어떤 누수가 생기는가?
답: 해당 시점에는 알 수 없는 이동을 입력에 제공한다. 정답 보간에는 이후 기록을 쓸 수 있으나
입력 특징·팀 집계·공간 사전에는 그 미래를 넣을 수 없다.
