# v14 변경 사항과 해석 범위

v12의 예측 과제·변수 정의·세 연구질문을 유지하고 Widom 버전의 정의 우선 설명을 적용했다. 이후 사용자의 요청에 따라 모든 결과를 패치 분할 재학습으로 교체했다. 따라서 v12의 수치나 결론을 고정한 편집본이 아니다. 과학적 정의를 보존하되 새 결과가 기존 주장과 다르면 결론을 바꿨다. v12/v13 원본은 수정하지 않았다.

## 데이터와 평가

- 패치 40.2 학습, 41.1 검증, 41.2 시험. 전체 13,948경기, 817,766 팀·단계 행의 특징과 전처리를 다시 구성했다.
- 학습 50경기 이상인 11개 코호트를 주 분석으로 삼았다. Karakin은 학습 6경기이므로 탐색 분석으로 분리했다.
- 같은 자료를 이전 분석에서 사용했으므로, 새로 수집한 미공개 시험 자료나 전향적 재현이라고 부르지 않는다.
- 전체 AUC, 사람 팀 AUC, 단계 내 AUC, 경기·단계 내 AUC, NLL/Brier/보정오차, 원래 생존 과제의 우승 정확도/C-index를 구분했다.

## 추가한 실험

- 두 큰 코호트에서 GBDT, KRAFTON 파생 backbone, PTR를 각각 16설정으로 탐색하고 검증 NLL로 선택한 설정을 3시드로 평가했다.
- 학습 구간을 정렬한 weighted survival/표준 Cox/BCE 5조건, 목적함수×확률변환 2×2, 사람 팀 손실/AI 입력 제거, 현재 입력/과거 요약, 과거 순서 섞기 대조를 추가했다.
- 주요 그래프 모델 계열을 조사한 뒤 edge-feature GATv2 하나를 선정했다. 같은 16설정·3시드와 관계 재배열 대조를 적용했다. 선정 근거는 학습 그래프의 작은 크기와 높은 연결 밀도, 연속 간선의 종류·강도·방향이다. 선택 시점상 탐색적 확장으로 명시했다.
- 동일 시행 횟수가 동일 연산량을 뜻하지 않는다. 신경망 규모·실행시간을 기록하며, CPU에서 실행한 추가 대조에는 같은 CPU의 참조 모델을 사용했다.

## 선행연구 코드 교정

KRAFTON의 고정 원본과 핵심 출력·기울기를 대조했다. 표준 Cox와 다른 공개 weighted objective 및 원 코드의 snapshot winner Brier를 정확히 명명했다. 입력 일부가 대리변수이고 원래 데이터/체크포인트가 없으므로 원 성능을 완전 재현했다고 주장하지 않는다.

Sagong 적용판에서 다른 팀의 공격자를 어시스트로 세던 오류를 고쳤다. 특징 생성 코드가 바뀌면 캐시를 재생성하도록 했고 수정된 60개 적합을 사용했다. 추가 손실 실험의 검열 시각과 이력 요약의 관측 마스크도 교정했다. 수정 전 결과는 별도 보관하고 최종 집계에서 제외했다.

## 달라진 핵심 해석

- 전체 비교의 GBDT/PTR 평균 AUC는 0.768/0.769이고, 원래 생존 과제의 우승 예측에서는 KRAFTON 적용판이 더 좋다. 평가 과제가 모델 순위를 바꾼다.
- 다음 단계로 Cox의 학습 구간을 맞추면 BCE의 경기 내 우위 대부분이 사라진다. 따라서 이를 손실 함수 자체의 보편적 우위로 해석하지 않는다.
- 다섯 구조 비교 중 세 개는 실용적 동등, 팀 축의 두 비교는 판단 유보다. 모든 구조가 무효라는 결론은 삭제했다.
- 사람 팀 분석과 AI 보정을 추가하면 이동 잔차의 연관성이 약해진다. 경쟁 밀도와 생존 멤버 수의 방향은 유지된다.
- 우리 특징이 모든 조건에서 더 좋은 것은 아니다. KRAFTON 특징과 합치면 더 좋아지는 상보성이 나타났다.
- 목적함수와 확률변환의 기여는 공통 2×2와 경기 부트스트랩으로 다시 계산했다. 서로 다른 pooled 값을 더해 76%라고 쓰지 않는다.

## 보고 방식

인용번호는 본문 첫 등장 순이다. 원래 문헌을 유지하고 재현성·생존학습·탐색·기여 분해·GATv2 문헌을 추가했다. 계수는 관측적 연관성으로 쓰고, +1 단위 확률 변화는 미분 AME나 인과효과와 구별했다. 표와 그림은 새 분석 CSV에서 다시 생성했다. 최종 검증 기록은 `qa/final_validation.json`, 세부 리뷰 대응은 `REVIEW_RESPONSE_KO.md`에 있다.
