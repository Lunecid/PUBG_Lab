# v14 → v15 변경 사항

실험과 예측 결과는 동결하고, 첨부 SAC MLA 리뷰 중 현재 근거로 반영 가능한 항목을 수정했다.

- 제목·171단어 초록·기여를 과제 정렬, 입력 상보성, 평가 단위별 구조 효과 중심으로 정리했다. 입력 결합 GBDT AUC 0.786을 초록과 주 비교 도입에 추가했다.
- 입력 시점과 사후 위험집합을 구분하고, 포함 행에 대한 기존 검사만으로 온라인 표본 선택이 검증되지는 않는다는 한계를 명시했다.
- 코드와 대조해 nearest-position 창, 이동 잔차의 기간과 집계, 경쟁 밀도의 3차원 거리, 동일 시각 사건 및 로그 단절 제외 규칙을 구체화했다.
- 기존 phase-only/lite 결과의 절대 AUC·NLL·Brier를 추가했다. 새 실험 결과가 아니다.
- 구조 비교 5개의 90% CI·문턱·판정과 Holm p를 한 표로 모았다. 단측 우월성 검정의 보정과 미보정 동등성 구간을 구분했다.
- gain은 문턱 초과를 통계적으로 입증한 것이 아니라는 점과 사전등록·학습 변동성의 한계를 분명히 했다.
- 41.1 패치의 봇·장비 변경을 공식 자료로 확인했고, zone schedule의 공통성을 환경 불변성과 구분했다.
- 사후 경기 검토를 현재 적용 범위로 정하고, 온라인 위험집합·효용·실행 비용·새 단순 baseline 등 미완료 검증을 남겼다.
- 중복 설명을 줄여 참고문헌 포함 10쪽을 유지했다. 그림 3개·표 8개·참고문헌 39개이며, 참고문헌 번호는 첫 인용 순서다.

세부 항목의 완료/부분 반영/미수행 여부는 `REVIEW_RESPONSE_KO.md`, 출처와 해시는 `qa/revision_evidence.json`을 참조한다. v14 폴더 전체의 기존 파일 해시를 대조해 원본 보존을 확인한다.
