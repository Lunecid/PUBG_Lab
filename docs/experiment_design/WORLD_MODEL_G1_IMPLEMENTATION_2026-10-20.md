# G1: 학습 전 입력·인코더 구현과 반증 시험

2026-10-20. 저자: “그래 이제 더 진행해봐 자기 피드백을 반복하면서”.
직전 아키텍처 V3의 다음 단계인 제한된 구현·검증으로 진행한다.
긴 학습·optimizer step·경로 성능 비교는 이 실행에 포함하지 않는다.

## 적용 전에 제시한 패치

- 기존 `preprocess.py`, `dataset.py`, 완료된 v3 코퍼스는 보존한다.
- `world_model/inputs.py`: fit-only 범주 사전, 관측 마스크 우선 적용,
  명시적인 입력 자료형, 현재 상태만으로 정한 focal-team 인덱스, 정답 분리.
- `world_model/encoder.py`: 개인 시간 attention, 개별 무장·이동·피해 증거,
  공간의 관측/추정 관계, 팀원 집합과 상대 위치, 현재 zone·경기 문맥.
- `tests/world_model/test_encoder.py`: 구현 이전에 실패하는 계약 시험을 작성하고,
  정보 경계·순서 등변성·재진입·결측·빈 그래프를 반복 변형한다.
- `tools/verify_world_model_encoder.py`: 허용된 train/development 예시 CPU 순전파,
  역전파 연결 시험(가중치 갱신 없음), 자원·재현성·해시·시각화 기록.

## 최소 구현 결정과 근거

부품별 요구·문헌·반증의 기본표는 [V3](PUBG_WORLD_MODEL_ARCHITECTURE_V3_2026-10-20.md)를 따른다.
여기서는 HGT의 유형별 연산 원리를 단순화한 relation-specific mean message를 사용한다.
HGT 재현이라고 부르지 않는다. 공간은 S0(동일 patch의 fit 이동 증거)만 구현한다.
장비·차량·교전은 관측 증거 토큰으로 개인에 연결한다. 차량 ID를 복원했다고 하지 않는다.
팀은 개인 latent의 집합과 모든 유효 팀원 쌍의 상대 위치·거리 집합으로 표현한다.
centroid는 팀 위치의 대체값으로 사용하지 않는다.

| 부품 | 형태·비용 | 사전 반증 기준 |
|---|---|---|
| 입력 어댑터 | L×P×17 선형 마스크·척도 변환 | 숨긴 숫자/미래 정답 변화가 입력에 영향 → 실패 |
| 개인 시간 | 2층, d=128, 4 heads, dropout=0; O(P L²d) | 단절 이전 정보가 현재 요약에 전달 → 실패 |
| 공간 | 관측·추정 별도 message, 2회; O(E d²) | 두 관계가 구별되지 않거나 빈 공간에서 비유한 값 → 실패 |
| 팀 | mean 개인 표현 + nonlinear 상대 벡터 집합; O(Σ M²d) | 구성원 재배열 시 팀 표현이 atol=2e-5, rtol=2e-5 밖에서 변화 → 실패 |
| 개인 간 문맥 | 허용된 현재 개인들 사이의 상대 위치 attention; O(P²d) | server 적 위치를 바꾸어도 자기 팀 표현이 동일 → 전달 경로 실패 |
| 문맥 | 현재 zone의 상대 방향/경계거리 + 과거 game 요약 | 현재 알려진 zone 변화가 출력에 전혀 영향 없음 → 배선 실패 |
| 실행 | CPU 1 thread, seed=20261020, optimizer 없음 | 같은 환경 재실행 hash 불일치 또는 private 48 GiB 초과 → 실패 |

정규화는 사전 정의한 단위 변환이며 코퍼스 통계로 fit하지 않는다.
조건 어휘만 정확한 train ID 집합에서 구성한다. 새 patch는 UNK.
encoder는 미래 mask/종료 순위/인간·봇 label을 받지 않는다.
가변 크기 batching은 sample-list로 시작한다. 인위적인 4인 제한이나 잘라내기는 없다.

## 검토에서 선제 보완한 경계

- `alive_teams`의 HUD 가시성이 입증되지 않았으므로 observer 입력에서 제외한다.
- 재진입 episode 원본 ID는 읽지 않는다. 공개된 체력·관측 단절 및 개인에게 허용된
  episode age만으로 attention 경계를 만든다. 이것은 보수적인 단절 proxy다.
- t0 상대 좌표를 사용하므로 temporal 중간값을 과거 시각의 독립 예측값으로 해석하지 않는다.
  encoder 결과는 전체 과거 창을 이용하는 **t0 표현**이다.
- 미래 정답으로 현재 팀원 수를 줄이지 않는다. 완전 경로 코호트 여부는 정답 측에서만 계산한다.
  완전 코호트의 선택 편향과 전체 평가 분모를 후속 학습에서 함께 보고해야 한다.

## 자체 피드백 절차

계약 시험 → 최소 구현 → 실제 경로 확인 → 반례 추가 → 수정 → 재시험을 기록한다.
동일 에이전트의 자체 검토이며 독립 검토·다른 모델 점검으로 표시하지 않는다.
학습 효과·지형 정확도·승리 전략을 입증하는 단계가 아니다.

두 번째 검토에서 server 적 정보가 focal player에 전달되지 않는 반례가 실제 실패했다.
개인 간 상대 위치 message를 추가하는 패치를 제시한 뒤 수정했다.
관측자에서 적 노드를 새로 추정하거나 서버 정보를 가져오지 않는다.

최종 누수 검토: fit 전체 공간 prior에는 현재 경기의 미래 이동이 포함될 수 있다.
새 입력 어댑터에서 현재 경기의 관측 연결 수와 경기 기여분을 빼고,
cell support 및 추정 인접 관계를 다시 계산한다. 기존 전처리는 변경하지 않는다.
자기 경기의 공간 집계를 크게 바꾸어도 입력이 불변인 synthetic 반례로 확인한다.
다른 fit 경기들은 여전히 사전에 학습된 population prior다.
