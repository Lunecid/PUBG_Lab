# Warzone / Caldera RQ3 3D Render Evidence Package

Date: 2026-07-06
Class: `WorldModel`
Lifecycle: `active`

## Purpose

This document fixes how the thesis should use the existing Warzone / Caldera
3D modeling and rendering artifacts for `RQ3`.

The role of Warzone / Caldera is not to provide a second supervised survival
dataset.  It is to show, with geometry-rich evidence, which Battle Royale
terrain, topology, and spatial-affordance constructs are not directly
observable from official PUBG telemetry alone.

The manuscript placement is:

```text
RQ1 Battle Royale genre formalization
-> RQ2 PUBG official-telemetry mapping
-> RQ3 PUBG observability gap and Warzone / Caldera 3D representation
-> RQ4 PUBG phase-survival and final-outcome prediction
```

## Core RQ3 Claim

Safe claim:

```text
Official PUBG telemetry is label-rich for supervised phase survival and final
rank / top-k evaluation, but it does not directly provide the terrain mesh,
building mesh, route semantics, surface topology, or occlusion geometry needed
to represent fine spatial affordances.  Warzone / Caldera provides a
geometry-rich case showing how those missing constructs can be represented.
```

Do not claim:

```text
Caldera validates the supervised PUBG survival model.
```

Do not claim:

```text
The current render is a full game-engine reconstruction.
```

Do not claim yet:

```text
The current artifact proves line-of-sight, occlusion, or cover effects.
```

Line-of-sight remains a future ray-casting extension.

## What This Answers

This RQ3 package answers:

```text
PUBG official telemetry can represent phase survival and outcomes, but it does
not directly observe fine-grained terrain, building, route, or occlusion
geometry.  Warzone / Caldera demonstrates how a geometry-rich Battle Royale
world can provide those missing representational constructs.
```

It does not answer:

```text
Do those Caldera geometry features improve PUBG survival prediction?
```

It also does not answer:

```text
Do Warzone / Caldera labels support supervised final-rank prediction?
```

Those are outside the current evidence.
